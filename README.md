# Inventory-Sales-summative

Project Overview

This project is a Python-based Inventory and Sales Tracking System designed for a small shop. The application allows users 
to manage products, track inventory quantities, record sales, automatically reduce stock, identify low-stock products, 
and permanently store product and sales data using files.

Features

- Add products
- Display all products
- Search products
- Update product information
- Update quantities
- Record sales
- Automatically reduce stock
- Prevent insufficient-stock sales
- Calculate sale totals
- Display low-stock products
- Save and load data
